## 常见问题

**不限流量真的可以无限跑吗？**
流量上没有月度额度，但端口速度决定了实际上限。真实家宽标准版是100Mbps端口，跑满一个月大约32TB；家宽宽带环境常见的带宽范围是50到300Mbps。真不限的含义是额度不封顶，速度仍然受物理线路约束。

**超量降速之后速度会降到多少？**
官方页面没有公布降速后的具体数值。如果业务吃流量，与其赌降速后的表现，不如直接选4837的高带宽档位，额度用完之前大概率已经够用。

**需要Windows系统怎么办？**

**IP被平台封了怎么办？**
年付用户一年内可以申请免费换IP。住宅IP被封的概率比机房IP低很多，但不是零风险，业务量大的时候建议保留备份方案。
